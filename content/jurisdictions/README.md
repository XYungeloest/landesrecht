# Jurisdiktionen

Das kanonische Jurisdiktionsregister ist Code, nicht Content:
`packages/legal-core/src/config/jurisdictions.ts`. Dort stehen genau einmal die vier Länder,
ihre öffentlichen Bezeichnungen und Kurzbezeichnungen, ihre URL-Segmente und der gemeinsame
Ausgangsrechtsstand `SIMULATION_BASELINE_DATE` (2023-12-01).

Dieses Verzeichnis nimmt später redaktionelle Länderinhalte auf (Einleitungstexte,
Verkündungsblatt-Beschreibungen, Hinweise zur Rechtsüberleitung). Es enthält keine
Bezeichnungen oder Stichtage, die vom Register abweichen könnten.
